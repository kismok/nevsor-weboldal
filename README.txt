NÉVSOR WEBOLDAL

Fájlok:
- app.py
- requirements.txt
- templates/index.html
- static/style.css

Indítás helyben:
pip install -r requirements.txt
python app.py

Quaxly:
1. Válaszd a Python realm/spell-t.
2. Töltsd fel a teljes mappa tartalmát.
3. Startup command: python app.py
4. A PORT változót a Quaxly által adott portra hagyja az app kezelni.

Az adatbázis automatikusan létrejön: nevsor.db
